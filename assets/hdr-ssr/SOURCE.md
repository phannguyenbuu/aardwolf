# HDR / SSR demo reference assets

Copied from the user's local `D:/Dropbox/_Documents/Threejs/WebGL2-Screen-space-reflections/src/assets/` for the requested matching demo environment.

Original project: https://github.com/Domenicobrz/WebGL2-Screen-space-reflections

Includes cubemap sets 1 and 3, street albedo, normal and AO. No car model or car textures included. The source package declares ISC; third-party image rights should be verified before distributing these reference assets beyond the current development setup.

The application uses Three.js SSRPass with these visual assets, rather than the demo's older raw WebGL custom PBR shaders. Output is a visual adaptation for the user's editable product materials, not a claim of pixel-identical shading. The source cubemaps are JPEG images (LDR); the HDR mode label describes environment-lit rendering, not a Radiance HDR source file.
