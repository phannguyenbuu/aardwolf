# Customer feedback implementation 30 October 2026

The customer Word document supplied on 31 October is implemented as a five-step
customer configuration flow. The shared compatibility rules are in
`src/utils/selectionRules.js`; UI and quote validation both use them.

## Sources and interpretation

- `ref/1. BANG CHON APP 21 OCT.xlsx`, Sheet1 rows 5–12: crane/jib/WLL
  compatibility and allowed handle columns N–Q. The cell values match the copy
  named `1. BANG CHON APP 21 OCT 1.xlsx`.
- `ref/CONTROL HEAD'S 13 OCT 2.xlsx`, control heads rows 2–5: handle codes,
  names and prices. Customer `Visuals/Heads` provides the handle photographs.
- `ref/SUCTION CUP TABLE latest 13-OCT 2.xlsx`, `suction pad .new`, rows 7–35:
  contact dimensions, maximum Non-porous/Porous capacity, material families.
- `public/assets/configurator/sources.json` records extracted image provenance.
  Crane and jib thumbnails are rendered from the repository's own FBX meshes,
  with accessories removed. Material thumbnails are local SVG illustrations.

The feedback calls some capacities “minimum” and gives conflicting WLL 30 kg
examples. The workbook labels them maximum load capacity. Implementation uses
actual weight ≤ selected WLL and ≤ pad capacity for the selected permeability,
plus sufficient contact dimensions and material compatibility. It does not
disable a 35 kg pad merely because the tube WLL is 30 kg. Customer confirmation
of a different selection policy would require changing the centralized rules,
not duplicating conditions in the UI.

Workplace dust and load permeability are distinct. The new selection stores
`nonporous`/`porous`; it does not map porous loads to the old dusty-workplace
filter surcharge. Old configurations require explicit confirmation of the load
type before quoting. Metric unit state is normalized to `mm`; persisted `m`
selections continue to use metric units. Dimensions remain mm/kg internally.

## Customer behavior

1. Crane-only thumbnails, spread across the available column.
2. Jib thumbnails and lengths in mm or inches.
3. Existing WLL choices with the source crane/jib restrictions.
4. Permeability, six visible material cards, then Weight/Length/Width in one row.
   Height is retained internally for 3D dimensions and existing document exports.
   Weight cannot produce a quote above WLL and is corrected on blur.
5. All handles and pads are visible as image cards; incompatible/unavailable
   choices are disabled with explanations.

Changing upstream selections revokes downstream confirmations. Invalid pad
choices are revoked after weight or size changes. The load object is visible
only after material, handle and pad have been confirmed. Quote/Requote appear
only for a complete, valid selection and continue to the existing specification
page. Material selection updates the load's preview material.

Customer mode uses High Quality, disables shadow maps and ambient occlusion,
and hides render/capture, camera/fullscreen and mode controls. Existing Admin
tools remain accessible via `?admin=1` and the mode switch. That query is an
editor entry point, not an authentication mechanism; backend authorization is
unchanged.

The existing hose subdivision helper is now applied to Black Rubber meshes in
crane models. Subdivided geometry is cached per source, before material bevels.

## Asset limitations

The repo has no verified FBX for the Excel flat cup and single rectangular flat
pad. These products are listed with source images and capacities but stay
disabled rather than displaying an unrelated product. Consequently Stone and
Concrete remain unavailable until their compatible tooling models are supplied.
Existing catalog entries for 2x bellows Φ200/Φ300 also remain unavailable.

backend calls and substitutes a small FBX for large assembly files. It checks
the five sections, unit choices, WLL 30 kg handle restrictions, complete Quote
flow, resetting downstream selections, load visibility, hidden customer tools,
shadow maps, mobile width and image availability. It does not validate pricing
against a live account or the full photorealistic export service.
